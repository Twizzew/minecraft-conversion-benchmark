# Rule changes made while developing the MCCB v1.1 oracles

**Why this file exists.** The MCCB v1.1 comparison rules were written by the WorldSwitch
team, and refined while looking at WorldSwitch outputs (engine commit `0308840`). No other
converter had been run when these changes were made. Every change that altered a status
is listed here with its effect on the WorldSwitch counts, including — especially — the
changes that made WorldSwitch look better. A reviewer can re-run the tools at any entry
to check the numbers.

The rules are frozen by the hashes in `manifests/fixtures.json` and `reports/freeze/`
before any competitor is run (METHODOLOGY §8).

## MCCB v1.3 — rules 47–52 (2026-09-27/29)

Corrections of the four oracle defects found after the v1.2 freeze (F10–F13, reported in
the v1.2 technical report and never applied to v1.2 results). Written after WorldSwitch
(0308840 and later working-tree builds) and Chunker 1.20.0 had been graded under v1.2, and
while a WorldSwitch build fixing the structure defects that F13 describes was prepared —
the effect column says which converter each rule helps. Effects were measured on the
recorded outputs of `ws-0308840` (old WorldSwitch), `ws-0308840+6da882c` (same engine
files as the release commit `fd9b735`) and `chunker-1.20.0`, before
`reports/freeze/FREEZE-v1.3.json` was written. No rule changes after that file.
